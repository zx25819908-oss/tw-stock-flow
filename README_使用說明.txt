# 台股資金流動盤（免費行情估算版）

## 這是什麼
手機／電腦都可開的 Streamlit 網頁儀表板，顯示產業與個股的「估算資金方向」排行。

**重要：** 目前不是交易所的真實主動買賣淨額。它以股價漲跌、成交量估算資金方向，僅供觀察；資料可能延遲或缺漏。不要把估算值當成券商逐筆資金流或法人買賣超。

## 最簡單的啟動方式（電腦）
1. 安裝 Python 3.10 或更新版本。
2. 解壓縮此 ZIP，進入資料夾。
3. 開啟終端機／命令提示字元，執行：
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
4. 瀏覽器開啟終端機顯示的網址，通常是 http://localhost:8501 。

## 想在 iPhone 直接開啟
把這個資料夾上傳到 GitHub，再到 https://share.streamlit.io/ 建立免費 Streamlit Community Cloud app，選擇 `app.py` 部署。部署完成後會得到一個網址，可加入 iPhone 主畫面。
這一步需要你自己的 GitHub／Streamlit 帳號；我不能替你登入或代替你部署。

## 自訂股票
左側欄位可以輸入股票代號，以逗號分隔。預設樣本清單中的股票有產業分類；新加入代號會顯示為「未分類」，若要指定產業，請編輯 `app.py` 裡的 `STOCKS` 清單。

## 已知限制
- 免費 Yahoo Finance 行情不是保證即時的交易所行情。
- 預設是常見台股樣本，不是全市場完整清單。
- 部分代號可能抓取不到、遇到限流或缺少成交量。
- 真正的「主動買賣淨額」需要逐筆成交／委買委賣方向資料，通常需券商或行情供應商授權。
